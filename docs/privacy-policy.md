## 2. 本ポリシーの適用範囲と当社の立場

本サービスでは、当社の立場が異なる 2 種類の個人情報を取り扱います。

### 2.1 当社が自ら利用目的を定めて取り扱う個人情報

次の情報については、当社が個人情報取扱事業者として、自ら利用目的を定めて取得・利用します。

- **利用者に関する情報**（3.1）— 利用者（本サービスの利用を申し込む事業者）及びその担当者の情報。
- **本サービスの運用に伴い当社が自動的に取得する情報**（3.3）— アクセスログ及び稼働監視のためのログ。エンドユーザーの通信に由来する情報（IP アドレス、内部識別子等）が含まれますが、これらは当社が本サービスの安定運用及び安全の確保のために自ら利用目的を定めて取り扱うものです。

### 2.2 当社が利用者からの委託を受けて取り扱う個人情報

エンドユーザー（利用者が運営する EC サイト・業務システム等を経由して本サービスにより認証される方）を識別するために取り扱う情報（3.2）については、**利用者が個人情報取扱事業者となり、当社はその取扱いの委託を受ける立場**となります。

- 当社は、これらの情報を、認証機能の提供のために委託された範囲を超えて利用しません。
- エンドユーザーに対する利用目的の通知・公表、同意の取得、開示等の請求への対応は、**利用者の責任**において行われます（[EcAuth ご利用規約](./terms-of-service.md)第 29 条）。
- エンドユーザーの方は、まずご利用のサイトの運営事業者（利用者）にお問い合わせください。

### 3.2 エンドユーザーについて当社が保持する情報

当社は、エンドユーザーの識別に用いる情報について、**平文の電子メールアドレス等をそのまま保持しない設計**を方針としています。当社が保持するのは以下の情報です。

| 保持する情報 | 内容 |
|---|---|
| ハッシュ化された識別子 | 電子メールアドレス又はログイン ID を一方向のハッシュ関数により変換した値。当社は元の値をそのまま保持しません。 |
| 内部識別子 | 本サービスが払い出す識別子。 |
| 外部 IdP のサブジェクト識別子 | フェデレーション機能を利用する場合に、外部 IdP が払い出す識別子。 |
| パスキーに関する情報 | 公開鍵及び認証器に関する情報、登録名、登録日時、最終利用日時。**秘密鍵はエンドユーザーの認証器内にのみ存在し、当社に送信されることはありません。** |
| 外部 IdP のトークン | フェデレーション機能を利用する場合に、外部 IdP が発行したトークン。 |
| 認証処理に伴う一時的な情報 | 認証及び認可の処理のために生成され、短時間で失効するもの。 |

本サービスは、エンドユーザーの認証に必要な情報のみを取り扱う設計としており、氏名、住所、電話番号、生年月日、注文履歴及び決済情報を保持していません（外部 IdP がこれらの情報を応答に含める場合でも、当社のデータベースに保存しません）。また、本サービスはパスワード認証を提供しておらず、当社が**パスワードを保持することはありません**。

### 3.3 本サービスの運用に伴い自動的に取得する情報

本サービスの提供にあたり、アクセスログ及び稼働監視のためのログを取得します。これらには IP アドレス、User-Agent、アクセス日時、リクエストの内容、本サービスが払い出す内部識別子等が含まれます。利用目的は、障害の調査、性能の分析、不正アクセスの検知及び防止です。

これらのログには、利用者だけでなくエンドユーザーの通信に由来する情報も含まれますが、2.1 に記載のとおり、**当社が本サービスの安定運用及び安全の確保のために自ら利用目的を定めて取り扱うもの**であり、2.2 に定める委託の対象ではありません。当社は、これらのログを本項に記載した利用目的の範囲を超えて利用しません。

## 4. Cookie 等の取扱い

- 当社は、本サービスの提供、利用状況の把握及び品質の向上のために、Cookie 又はこれに類する技術（ブラウザのローカルストレージ等）を利用することがあります。
- 現在、本サービスのウェブサイトは、ログイン状態の保持のために、ブラウザを閉じると消去される `sessionStorage` を使用しています。
- 当社が通信の保護及び配信のために利用する CDN 事業者が、セキュリティ上の目的（不正なアクセスの検知等）で Cookie を設定する場合があります。
- Cookie 等を通じて取得した情報の利用目的を変更し、又は新たに広告配信等の目的で利用する場合には、本ポリシーを改定のうえ、9 章に定める方法によりお知らせします。

## 5. 保存期間

当社は、個人情報を利用目的の達成に必要な期間、及び法令上保存が必要な期間保存します。

- 認証及び認可の処理のために一時的に生成される情報（認可コード、チャレンジ、ログイン用リンク等）は、短時間で失効し、又は削除されます。
- 不正な大量請求の防止のために取得する IP アドレス及び User-Agent は、取得から一定期間の経過後に自動的に削除します。
- アクセスログ及び稼働監視のためのログは、一定期間の経過後に削除します。

利用契約が終了した後の取扱いは、情報の種類ごとに次のとおりです。

| 情報 | 契約終了後の取扱い |
|---|---|
| 組織コード | 他の利用者への再割当てによる誤接続を防ぐため、契約終了後も保持します。 |
| 利用者のアカウント情報、Organization 及びクライアントの設定 | 課金の集計及び紛争への対応に必要な期間保存します。 |
| パスキーの登録情報、エンドユーザーの識別子 | 認証機能の提供のために利用する必要がなくなった後は、削除のご請求に応じて削除します。 |
| 法令上保存義務のある記録 | 法令に定める期間保存します。 |

利用者が登録したパスキーは、契約期間中、マイページからいつでも削除できます。上記のほか、個人情報の削除をご希望の場合は、7 章に記載する手続により個別にご請求ください。個別の保存期間についても、同章の窓口にお問い合わせいただければご回答します。

## 8. 安全管理措置

当社は、個人情報の漏えい、滅失又は毀損の防止その他の安全管理のため、以下の措置を講じています。なお、安全管理措置に係る事項のうち、公表することにより本サービスの安全性を損なうおそれのあるものについては、記載を差し控えています。

**組織的安全管理措置**

- 個人情報の取扱いに関する留意事項を定め、取扱状況を把握できる体制を整備しています。
- 個人情報を取り扱う担当者を限定しています。

**人的安全管理措置**

- 個人情報の取扱いに関する留意事項について、担当者に必要な周知を行っています。

**技術的安全管理措置**

- 本サービスへの通信を暗号化しています。
- パスワードを保持しない認証方式（パスキー及び電子メールで送付するログイン用リンク）を採用しています。
- エンドユーザーの識別に用いる情報をハッシュ化して保持しています。
- 利用者の認証情報を暗号化して保存しています。
- 個人情報を取り扱う情報システムへのアクセスを制限し、その状況を記録・監視しています。
- ログに記録する情報を必要最小限にとどめています。
- 不正な大量請求を防止するための制限を設けています。

**外的環境の把握**

- 6.2 及び 6.3 に記載のとおり、外国にある第三者に個人情報の取扱いを委託しています。当社は、これらの国における個人情報の保護に関する制度を把握したうえで、安全管理措置を講じています。
