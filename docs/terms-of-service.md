スキルニル株式会社（以下、「弊社」）が提供する認証サービス「EcAuth」（以下、「本サービス」）のご利用条件を定めるものです。

## 第1章 総則

### 第1条 定義等

1. 本規約は、弊社が提供する本サービスの利用に関し、次項第 1 号に定める利用者に適用されます。
2. 本規約において用いる用語の定義は、以下の各号のとおりとします。
   1. 「利用者」とは、本規約に同意のうえ弊社と利用契約を締結し、本サービスを自己の運営する EC サイト・業務システム等に組み込んで利用する事業者をいいます。
   2. 「エンドユーザー」とは、利用者が運営する EC サイト・業務システム等を経由して本サービスにより認証されるすべての自然人（管理者・スタッフ・顧客等）をいいます。エンドユーザーは本規約の当事者ではありません。
   3. 「Organization」とは、本サービスにおけるテナントの単位をいい、利用者が登録するサイトごとに割り当てられます。
   4. 「クライアント」とは、Organization 配下で本サービスへ接続するアプリケーション（EC-CUBE 等）の登録単位をいいます。
   5. 「外部 IdP」とは、本サービスがフェデレーション連携する第三者の認証プロバイダーをいいます。連携の対象となる外部 IdP は弊社が別途定めるものとし、その追加、変更又は廃止は弊社の裁量によります。
   6. 「パスキー」とは、WebAuthn 仕様（W3C Web Authentication）及び FIDO2 仕様に基づく公開鍵暗号方式によるクレデンシャルをいいます。
   7. 「B2B 認証」とは、利用者が運営するシステムの管理者・スタッフ等を対象とする認証機能をいいます。
   8. 「B2C 認証」とは、利用者が運営するシステムの顧客・エンドユーザーを対象とする認証機能をいいます。
   9. 「技術ドキュメント」とは、本サービスの機能仕様、API 仕様、接続手順等について弊社が公開するドキュメント（OpenID Connect Discovery ドキュメント、接続プラグイン及びクライアントライブラリに付属する README 等を含みます。）をいいます。

### 第2条 規約の適用及び変更

1. 利用者は新規利用、および利用継続中において、本規約に同意しているものとみなします。
2. 本規約に同意いただけない場合には、本サービスを利用することができません。
3. 弊社がオンラインまたはその他の手段を通じ、随時利用者に対して通知する諸規定（料金規定、プライバシーポリシー、技術ドキュメント等を含むがこれらに限られない）は本規約の一部を構成するものとします。
4. 弊社は、以下の各号のいずれかに該当する場合、利用者の承諾を得ることなく、本規約を変更できるものとします。
   1. 変更内容がサービス名や表現の変更又は誤字、脱字の修正等であり、本規約の内容に実質的に影響しない場合
   2. 変更内容が利用者の一般の利益に適合する場合

6. 本規約に変更がなされたことが通知された後に利用者が本サービスの利用を継続した場合は、本規約の変更を承諾したものとみなします。
7. 弊社は、本規約に版数を付して弊社が指定する場所に掲載し、過去の版及び変更の履歴を利用者が確認できる状態に維持するものとします。

### 第3条 サービスの内容

1. 本サービスは、利用者にエンドユーザーの認証のための Identity Provider 機能を提供するものであり、提供機能は次の各号を含みます。ただし、各機能の提供開始時期及び提供範囲は、弊社が別途定めるところによります。
   1. WebAuthn / FIDO2 仕様に基づくパスキー認証機能（B2B 及び B2C）
   2. OAuth 2.0 / OpenID Connect プロトコルに基づく外部 IdP とのフェデレーション機能
   3. 利用者向けの Organization・クライアント管理機能（利用申込、サイトの追加及び削除、Client Secret の発行及び再発行、Redirect URI 及び許可 RP ID の設定を含みます。）
   4. 利用者の管理担当者を対象とする、電子メールで送付するログイン用リンクによる認証機能（パスキーが利用できない場合の代替手段として提供するものです。）
   5. 接続プラグイン及びクライアントライブラリの提供
   6. その他弊社が本サービスとして提供することを定めた機能
2. プランの内容は別途弊社ウェブサイト上、電子メールまたは書面で定めるものとします。
3. ただし、弊社は、プランの構成または内容を任意に変更する場合があります。この変更手続については第 2 条の定めを準用します。
4. 本サービスは Identity Provider としての認証情報の発行・検証を提供するものであり、本サービスを通じて発行された認証結果に基づくセッション管理、アクセス制御、業務処理は利用者の責任において実装・運用されるものとします。
